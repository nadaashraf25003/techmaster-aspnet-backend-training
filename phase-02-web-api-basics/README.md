## How To Run
1. Open terminal and navigate to the project directory (e.g., `cd phase-02-web-api-basics/task-00-api-setup`).
2. Run the project using `dotnet run`.
3. Open the Swagger UI at `https://localhost:<port>/swagger` or `http://localhost:<port>/swagger`.
4. Test endpoints directly via Swagger or Postman.
